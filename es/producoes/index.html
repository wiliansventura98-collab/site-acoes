Cómo incluir una producción

La lista viene del archivo dados/producoes.csv, una planilla simple (se abre en Excel), con una fila por producción. Para agregar un ítem, edite ese archivo en GitHub o use el formulario de sugerencia (se necesita una cuenta en GitHub). La página se actualiza sola en la publicación siguiente.

Columnas: ano (año), tipo, titulo, autores, onde (dónde se publicó o presentó), link, resumo (en portugués) y resumo_es (en español, opcional). Tipos usados: Artigo, Capítulo de livro, Livro, Apresentação, Tese ou dissertação, Relatório, Material didático, Base de dados, Documento técnico (se muestran traducidos).
