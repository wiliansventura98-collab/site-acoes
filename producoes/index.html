Como incluir uma produção

A lista vem do arquivo dados/producoes.csv, uma planilha simples (abre no Excel), com uma linha por produção. Para acrescentar um item, edite esse arquivo no GitHub ou use o formulário de sugestão (é preciso ter uma conta no GitHub). A página se atualiza sozinha na publicação seguinte.

Colunas: ano, tipo, título, autores, onde foi publicado ou apresentado, link, resumo (em português) e resumo_es (em espanhol, opcional). Tipos usados: Artigo, Capítulo de livro, Livro, Apresentação, Tese ou dissertação, Relatório, Material didático, Base de dados, Documento técnico.
